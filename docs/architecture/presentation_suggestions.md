# 📊 Visual Suggestions for Research Paper & PPT

This document provides suggestions for figures and visuals to include in a research paper or presentation based on the MediAssist AI project.

---

## 📝 Research Paper Figures

1.  **System Architecture Diagram**
    *   **Description**: A detailed block diagram showing the data flow from user input to the safety layer and output.
    *   **Style**: Vector graphic (EPS or high-res PDF), clean lines, professional color palette (e.g., blue/gray/teal).
    *   **Content**: Include the Input Detector, Classical ML path, Transformer path, Fusion node, Safety Layer (Uncertainty & Top-K), and the final outputs (Diagnosis, Explanation, Referral).

2.  **Normalized Confusion Matrix**
    *   **Description**: Heatmap showing the performance of the best model (Logistic Regression or Hybrid).
    *   **File**: `reports/figures/confusion_matrices/logistic_regression_cm_normalized.png` (generated by the evaluation script).
    *   **Caption**: Discuss the classes with high confusion and relate them to symptom overlap (e.g., overlapping symptoms in viral infections).

3.  **Unsafe Prediction Rate (UPR) vs. Confidence Threshold**
    *   **Description**: A line plot showing how UPR decreases as the confidence threshold increases, illustrating the trade-off between coverage and safety.
    *   **Why**: Critical for demonstrating the safety aspect of the system in a healthcare context.

4.  **Top-K Accuracy Comparison Bar Chart**
    *   **Description**: Bar chart comparing Top-1, Top-3, and Top-5 accuracy across all models.
    *   **Why**: Shows that even if Top-1 accuracy is not perfect, the correct disease is almost always in the Top-3, which is valuable for preliminary screening.

## 💻 PowerPoint (PPT) Visuals

1.  **The "Problem" Slide**
    *   **Visual**: A split screen showing "Traditional Chatbot" (Confident but wrong) vs. "MediAssist AI" (Aware of uncertainty and safe).
    *   **Text**: Highlight the danger of overconfident AI in healthcare.

2.  **Model Comparison Table (Simplified)**
    *   **Visual**: A clean table showing Accuracy, Top-3 Accuracy, and UPR for the top 3 models.
    *   **Highlight**: Highlight the Hybrid or Best model row in a different color.

3.  **Case Study / Walkthrough**
    *   **Visual**: A mock screenshot of the Streamlit interface showing a successful interaction.
    *   **Scenario**: User enters ambiguous symptoms $\rightarrow$ System flags uncertainty $\rightarrow$ Returns Top-3 possibilities and recommends a specialist.

4.  **The Safety Layer Flow**
    *   **Visual**: A simple decision tree graphic showing: Confidence Check $\rightarrow$ Uncertainty Check $\rightarrow$ Action (Predict or Warn).
